驗證：各分數區間之後的實際漲跌

從隔天開盤起算，之後 5／20／60 個交易日的加權指數報酬與上漲機率。區間越偏多，後續報酬應該越高，這個指標才有用。

驗證：每一段漲跌波段，分數準不準

把 2017 年以來加權指數每次漲跌超過 10% 的轉折切成波段，看照分數操作在每一段賺賠多少。好的指標應該在上漲段吃到大部分漲幅、在下跌段少賠甚至賺。「轉弱/轉強確認」是轉折後分數要幾天才翻到對的方向（高點後 ≤ 40、低點後 ≥ 60）。

驗證：各因子單獨的預測力

因子數值與之後 20 日報酬的等級相關係數（IC）。正值代表方向正確；0.05 以上算有用，0.10 以上算強。兩段期間都是正的才可信。自營商兩段方向不一致，所以只列出參考、不計分。
指標怎麼算

資料：每天盤後抓上市、上櫃的外資與自營商買賣超，外資台指期未平倉，美元兌台幣匯率，以及加權、櫃買指數。所有法人數據都和自己過去一年的分布比較（Z 分數），不受市場規模逐年放大影響。

研究發現（2017–2026）：外資現貨買賣超單獨用來預測大盤效果很弱；外資台指期未平倉的「水位」會翻轉，不能直接用。比較可靠的是：

  • 外資台指期 5 日／20 日的增減倉方向
  • 指數趨勢
  • 台幣趨勢：台幣站上自己的 60 日均線（升值趨勢）時，之後 20 日表現較好，兩段期間都成立
  • 「跌深＋外資大賣」之後通常反彈（你觀察到的相對低點）
  • 只有在「空頭趨勢＋期貨加空＋現貨賣超」三者同時成立時，之後才明顯下跌

計分：

  • 指數趨勢 ×2、外資期貨增減倉 ×2、外資現貨 ×1、台幣趨勢 ×1、空方共振 ×1，加權平均後轉成 0–100 分
  • 指數跌破季線 4% 以上時，偏空的部分逐步打折，跌破 10% 時偏空訊號歸零（跌深不追空）
  • 恐慌賣壓（外資 20 日大賣且距一年高點 −8% 以上）直接加分
  • 指數乖離過大不扣分，因為研究顯示過熱之後多半續漲

驗證：權重只看 2017–2022 決定，2023 年起當作沒看過的資料檢驗。回測假設 T 日盤後算分、T+1 日開盤進場，每次換部位扣 0.05% 成本。

部位對照：強力偏多、偏多 → 做多 100%；中性 → 做多 50%；偏空 → 空手；強力放空 → 放空 50%。台股長期向上，研究顯示中性時完全空手會錯過太多漲幅，所以採偏多配置，只在最弱的時候才放空。
